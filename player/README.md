# HuaiDJ 本機播放器

按下載面板的「獨立播放器」，或執行 `player/start.cmd`。它使用獨立視窗，可拖動標題列與調整視窗大小；下載面板可關閉。預設不自動播放，點歌曲旁播放鍵或雙擊曲目才出聲。

- 曲庫：顯示 ACE 歌曲及 MP3、WAV、分軌的實存狀態；確定缺檔與待核對分開。搜尋曲名、檔名或路徑，按格式／狀態篩選。
- 後臺補檔後約 5 秒自然更新；資料未變不重畫，正在輸入或編輯清單時延後更新，播放繼續。
- 本機檔案：瀏覽目前 `Downloads/ai音樂` 裡的音檔；未能對應歌曲的檔案也可看見與播放。只開放這個曲庫，不掃描整台電腦。
- 播放控制：上一首／下一首、拖動進度、音量、靜音、隨機及循環；支援系統媒體鍵。Space 播放／暫停，Alt + 左右鍵切歌；輸入文字時不攔截 Space。
- 清單：新增／改名／刪除播放清單，加入曲目、調整順序；有佇列、本機收藏與播放歷史。精簡播放可收起曲庫。
- 網站點讚：讀取 acemusic.ai 歌曲卡片的拇指向上（`meta.rating === "good"`），啟動時及每 10 分鐘唯讀同步，也可按「同步網站點讚」。全部分頁成功才替換；失敗保留上次資料並顯示原因。尚未下載的歌曲也會列出並標示「尚無本機音檔」。播放器不會更改網站上的讚，心形「本機收藏」是另一個獨立清單。設定 `ACE_PLAYER_SITE_LIKES=0` 可關閉自動同步。
- 面板某首歌曲的播放鍵先定位該曲；播放器正在播另一首時不打斷。分類搬移後用實體檔案 ID 更新清單，單純同名不合併。
- 保存：清單與位置存在 `%LOCALAPPDATA%/AceMusicDL/player-state/state.json`；瀏覽器另留未提交草稿。多視窗發生版本衝突時保留草稿並提供比較／匯出，不靜默覆蓋另一個視窗。

服務只綁 `127.0.0.1:8790`，透過 opaque file ID 提供本機音訊 Range 串流，不提供任意路徑讀取。播放器不購買分軌、不生成音樂，也不替你補下載檔案；下載由原面板／CLI 負責。關閉視窗會保存狀態，服務可供下次直接開啟。

開發入口：`node agent/cli.mjs player --background --json`。隔離測試可設定 `ACE_STATE_DIR`、`ACE_DOWNLOAD_DIR`、`ACE_PLAYER_STATE_DIR`、`ACE_PLAYER_PORT`，不要將測試資料寫入真曲庫。
