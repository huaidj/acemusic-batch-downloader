# 設計系統（DESIGN SYSTEM）

> 適用：擴充功能面板、電臺播放器、隨機提示詞區，以及之後的 SUB RITUAL 獨立前臺。
> 唯一真源：[`design/tokens.css`](../design/tokens.css)。🔒 標記的規則由 `test/unit/design.test.mjs` 把關。

## 1. 定位：一個安靜的工具

這是用來「聽、選、下載、整理、寫提示詞」的音樂工具，不是聊天玩具。介面的工作是**把資訊讓位給聲音與檔案**：密度高、層級清楚、不吵。

- **一個強調色**（低彩度琥珀）只用來指出「可操作的主要東西」與「目前狀態」：主按鈕、勾選、進度、正在播放。其餘全是石墨底與暖灰文字。
- **狀態色只有三種**：綠（完成）、琥珀（注意／部分）、紅（錯誤／收藏愛心）。
- **文字說人話**：直接說缺什麼（「缺 MIDI」），不說「部分 2/3」；錯誤說下一步怎麼做。

### 1.1 「去 AI 味」清單（違反就退回）

| 不要 | 要 |
|---|---|
| 藍紫漸層、彩虹漸層、漸層文字 | 實色；強調色只有一個 🔒 |
| 發光、光暈、霓虹陰影 | 兩層普通陰影 🔒 |
| ✨ 🚀 🎲 等 emoji 當圖示；星星／火花符號代表「AI」 | 單色線條或實心 SVG 圖示（見 §5） |
| 「AI 驅動」「智能」「魔法」之類標語 | 描述它實際做什麼 |
| 置中大標題＋副標＋三張等寬卡片的行銷式版面 | 工具式版面：左側導覽／頂部分頁＋內容＋底部播放器 |
| 過大的圓角、卡片套卡片、處處玻璃擬態 | 圓角 6–14px；只有「浮動面板」用半透明＋模糊 |
| 假的進度、假的波形、假的音壓／相位儀 | 沒有資料就顯示簡單進度條或留空 |
| 一律用大按鈕、大間距「呼吸感」 | 4px 網格、緊湊控制項（工具要高密度） |
| 載入時整頁骨架動畫閃爍 | 就地顯示狀態文字，保留已有內容 |

## 2. 色彩

深色為預設，面板只有深色；前臺可加淺色（`:root[data-theme="light"]`，強調色換深一階以維持對比）。

| Token | 深色 | 用途 |
|---|---|---|
| `--bg-rgb` | `24, 23, 21` | 暖石墨底；半透明用 `rgba(var(--bg-rgb), var(--alpha))` |
| `--text` / `--muted` / `--faint` | `#ece8e1` / `#a8a299` / `#7a756d` | 主要／次要／輔助文字（輔助文字不得承載必要資訊） |
| `--line` / `--line-strong` | 暖白 8% / 14% | 分隔線／控制項邊框 |
| `--surface` / `--surface-hover` | 暖白 4% / 8% | 按鈕、列表懸停底 |
| `--field` | 黑 28% | 輸入框底 |
| `--accent` / `-hover` / `-ink` / `-soft` | `#d2a24c` / `#ddb062` / `#1c1913` / 14% | 唯一強調色；`-ink` 是它上面的文字色 |
| `--ok` / `--warn` / `--err` | `#9fc49b` / `#e0b45c` / `#e3907f` | 完成／注意／錯誤（各有 `-soft` 底） |

規則：
- 🔒 元件樣式**不得寫死 `#色碼`**，一律引用變數（品牌色彩只定義在 `:host`／`:root`）。
- 文字對比：`--text` 對底 ≥ 7:1；`--muted` ≥ 4.5:1；`--faint` 只用於可有可無的輔助資訊。
- 狀態不能只靠顏色：徽章一定帶文字（「已下載」「缺 MIDI」），愛心有填滿／空心兩態並有 `aria-pressed`。

## 3. 字體與字級

字體：`system-ui, "Segoe UI", "Microsoft JhengHei", "PingFang TC"`（不載入網頁字體，速度優先；等寬用 `ui-monospace`，只給提示詞、路徑、seed）。

| Token | 大小 | 用途 |
|---|---|---|
| `--fs-1` | 10.5px | 計數、輔助 |
| `--fs-2` | 11.5px | 次要資訊、徽章 |
| `--fs-3` | 12.5px | 控制項、內文 |
| `--fs-4` | 14px | 區塊標題（粗 700） |
| `--fs-5` / `--fs-6` | 17 / 20px | 前臺頁面標題／空狀態大數字 |

字重只用 400／600／700。時間、字數、檔數用 `font-variant-numeric: tabular-nums`（數字不跳動）。

## 4. 間距、圓角、陰影、動態

- **間距**：4px 網格（`--sp-1…6` = 4/8/12/16/24/32）。面板內容左右 14px、控制項間距 6–8px。
- **圓角**：輸入／晶片 6、按鈕 8、主按鈕／卡片 10、面板 14、膠囊 999。
- **陰影**：兩層（`--shadow-1`、`--shadow-2`），純黑、不帶色、不發光。
- **動態**：只做狀態回饋，≤150ms；播放中的圓點可脈動，但 `prefers-reduced-motion` 下全部關閉 🔒（tokens.css 全域規則）。

## 5. 圖示

- 單色、`currentColor`、24 網格、描邊 1.7px 圓端點，或實心（播放／暫停／上下首）。
- 現有圖示集在 `src/content.js` 的 `ICONS`（播放、暫停、上一首、下一首、隨機、循環、愛心、音量）。新增圖示加進同一張表，不從外部載入圖片或字型圖示。
- 列表內圖示按鈕 26px、播放器按鈕 30px、主播放鍵 38px。

## 6. 元件規格

| 元件 | 規格 |
|---|---|
| **主按鈕** `.primary` | 實色 `--accent`，文字 `--accent-ink`，圓角 9，粗 700；停用＝灰底灰字（不是半透明） |
| **次按鈕** `.ghost`／工具列按鈕 | `--surface` 底、`--line` 邊、`--text`；懸停 `--surface-hover`；不換行（`white-space: nowrap`） |
| **開關狀態按鈕** `.on` | 邊框與文字 `--accent`，底 `--accent-soft` |
| **圖示按鈕** `.pbtn`／`.rowicon` | 無邊框透明底；懸停淡底；`on` 狀態換色（隨機／循環＝強調色、收藏＝`--err`） |
| **徽章** `.badge` | 膠囊、11px；`ok`／`warn` 帶柔和底與同色邊；`dim` 降低不透明度 |
| **晶片** `.chip` | 膠囊、可點、用於歷史／標籤 |
| **輸入框／下拉** | `--field` 底、`--line` 邊；聚焦邊框變 `--accent`；提示詞區用等寬字 |
| **滑桿** | `accent-color: var(--accent)`；透明度、音量、進度同一種 |
| **列表列** `.song` | 懸停 `--surface`；正在播放 `--accent-soft`；封面 30px；右側依序：播放、收藏、下載 |
| **進度條** `.bar` | 4px、實色 `--accent`（整理條用 `--ok`），無漸層 |
| **提示條** `.randnote` | `--warn-soft` 底、警示文字；用於「這個模型沒有詞典」之類的限制，不用彈窗 |
| **浮動面板** `.panel` | 半透明 `rgba(var(--bg-rgb), var(--alpha))`＋背景模糊；標題列可拖曳；透明度滑桿 40–100% |
| **可及性** | 所有可聚焦元素 `:focus-visible` 為 2px 強調色外框 🔒；按鈕有 `aria-label`／`title`；狀態用 `aria-pressed` |

## 7. 版面

### 7.1 擴充功能面板（現況）
由上到下：標題列（拖曳、透明度、重新整理、關閉）→ **電臺播放器** → **隨機提示詞**（可收合）→ 下載選項 → 工具列 → 歌曲列表 → 進度 → 底部主按鈕。寬 470px、最大高 80vh；列表區是唯一捲動區。

### 7.2 SUB RITUAL 前臺（規劃）
三個頁面＋固定底部播放器；小螢幕用分頁與抽屜，不塞三欄。

```
┌ 頂部：專案名 ｜ 電臺 · 創作實驗 · 曲庫 ｜ 設定 ─────────────────────┐
│ 內容區（max 1180px，4px 網格）                                       │
│   電臺：佇列＋目前曲目詳情（所屬實驗／參考／詞條）                      │
│   創作實驗：自然語言框 → 參考槽(3) → [提示詞｜12×12 矩陣｜實驗對照]      │
│   曲庫：搜尋／篩選／收藏／加入佇列                                     │
├ 底部播放器（--player-h 64px，固定）：封面 · 標題 · 進度 · 控制 · 音量 ─┤
```

**12×12 矩陣**：144 格、列 A（低頻／上層音色世界）、欄 B（手鼓／小打／空間）。格子只用**單色相的明度階**表示「選擇權重」（`--accent` 由 0% 到 40% 的 alpha），**不用彩虹熱圖**；權重 0 的格子用刪除線＋`--faint`。選中格用 `--accent` 邊框，不放大、不發光。懸停顯示該格的中文名與字數／上限。

**模型區分（必做）**：頁面頂部永遠顯示目前「音樂模型 · 模式 → 目標欄位（上限 N 字）」，模型無詞典時用 `.randnote` 說明並停用「套用」；不可只靠顏色表示。

## 8. 內容語氣

- 具體、短、可行動：「站點限流：MIDI／MusicXML 先略過，其他檔案繼續下載；稍後再按一次下載即可補齊」。
- 不誇大：不說「智能」「完美」「一鍵搞定」；沒做的功能不放按鈕。
- 數字帶單位與上限：`756/1000 字`。
- 繁體中文為主，技術名詞保留英文（MIDI、WAV、Style、seed）。

## 9. 驗收（設計層）

1. `node --test test/unit/design.test.mjs`：面板色彩＝tokens、無寫死色碼、無漸層／發光。
2. 目視：深色背景與亮色背景頁面上，半透明面板文字都清楚（e2e 截圖）。
3. 鍵盤：Tab 走遍所有控制項、焦點外框清楚；空白鍵／Esc 不被站點攔截。
4. `prefers-reduced-motion` 下沒有動畫。
5. 新元件必須只引用 token；新增顏色先改 `design/tokens.css` 並更新本文件色卡。
